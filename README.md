# Ceylono — Studio Editorial UI

A visually redesigned, responsive React + Vite prototype based on the uploaded Ceylono project.

## Run

```bash
npm install
npm run dev
```

## What's changed

- Replaced generic dark-dashboard/glassmorphism with a custom editorial travel aesthetic.
- More human travel copy and fewer artificially technical labels.
- Full-bleed photo hero with working destination controls.
- Architectural use of whitespace, an intentional typographic scale and a forest/ivory palette.
- Destination explorer with detail dialogs, working interaction and keyboard-close support.
- Asymmetrical editorial experience stories; no cloned glowing cards or fake awards.
- Travel-brief composer with working selections and copy-to-clipboard.
- Mobile navigation, responsive sections and reduced-motion accommodations.

## Before going live

This is a design prototype. Existing external Unsplash image URLs are retained from the original concept: replace them with licensed, destination-verified original photography for a production travel site. The travel brief is copied to the clipboard, not transmitted or booked. To accept enquiries, connect an actual verified business email address or backend with consent and success/error handling. Review destination content for travel accuracy.
